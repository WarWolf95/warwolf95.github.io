# Maulik Parmar - Web Portfolio

Source code for Maulik Parmar's personal Data Analyst & BI Developer portfolio website, deployed via GitHub Pages.

**Live Website:** [https://warwolf95.github.io](https://warwolf95.github.io)

---

## Tech Stack
* **Markup & Structure:** Semantic HTML5
* **Styles & Design System:** Vanilla CSS (CSS tokens, dark mode, responsive grid, glassmorphism)
* **Scripting:** Vanilla JavaScript (filtering, lightbox modal, smooth scrolling)
* **Hosting:** GitHub Pages (SSL-secured, 100% uptime, zero cold starts)
